A taskbar for macOS. Or a better Dock.

Every window one click away, with live previews, a ⌘ Tab that switches windows, clipboard history and more. Run it as a taskbar, a floating dock, or on top of the real Dock.

What it adds.

Window tabs and the Start Menu belong to the AeroBar modes. Previews, the switcher, clipboard history and the shelf work in all four.

⌘Tab, rebuilt.

A switcher with live window previews. ⌘Tab moves between apps and ⌘` between windows of one app. Include apps with no windows, go minimal, or pause it in apps that need the system switcher.

A Start Menu with real depth

Click the Aero Orb to search apps and files, pin favourites to a drag-to-reorder grid, open recent files, and lock, log out, restart or shut down.

Searchable clipboard history

Every snippet, link and code block you copy, with keyboard navigation, rich previews and an encrypted, password-protected backup.

Music, stats and a shelf.

Controls for Spotify, Apple Music or any web player. CPU, RAM and network at a glance. A shelf to park files and drag them out later. Each has its own hotkey.

Small things, in motion

Dynamic Tint & AuraBarThe bar samples the active window’s colour, with per-app overrides. AuraBar carries the same glass to the menu bar.
Screen Search & Quick LinksSearch what’s on screen with Google Lens, and drag URLs onto the bar to keep them one click away.
Tasks, Mission Control, Show DesktopA dropdown of open windows grouped by app, plus buttons for Mission Control, Show Desktop and the Trash.
Pinned apps and foldersDrag apps into the tray, pin folders to the shelf, and right-click any tab to pin its app.
Focus ModeDim non-hovered items and the wallpaper so your attention stays where it belongs.
Encrypted backupsPassword-protected local backup for clipboard history, app shortcuts and preferences.

Tailor every detail.

From glass tints to popup sizes, selection glows and borders. Make AeroBar match your desktop.

No telemetry. No analytics. No crash reporting. AeroBar works offline, and the code is GPL-3.0 so you can check. Read the privacy policy

Updates are signed, and the Update Basket checks each signature before installing. Links open in your browser only after you say yes. The beta code page keeps a small record per install, and the privacy policy lists exactly what.

Install in one command.

  1. Run the command, then open AeroBar.
  2. If macOS says the app is damaged, run the second command.
  3. Grant Accessibility access when asked, then click Start AeroBar.
Prefer a disk image? Download the DMG from the latest release. AeroBar isn’t notarized yet, so open it once from System Settings, Privacy & Security, Open Anyway.

Install with Homebrew

brew tap adityaonx/aerobar https://github.com/adityaonx/AeroBar && brew trust adityaonx/aerobar && HOMEBREW_NO_QUARANTINE=1 brew install --cask aerobar

If macOS says the app is damaged

xattr -rd com.apple.quarantine /Applications/AeroBar.app
