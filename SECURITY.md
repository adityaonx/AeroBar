## Reporting a Vulnerability

Use this section to tell people how to report a vulnerability.

Please report security vulnerabilities by creating a private security advisory on GitHub or by emailing the project maintainers directly. Do not open public issues for security vulnerabilities.

We will try to respond to reports within 48 hours and keep you updated on the progress towards a fix.
