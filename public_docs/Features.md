# AeroBar Features

### Taskbar Interface
- **Persistent Panel**: A borderless taskbar located at the bottom of the screen.
- **Blur Materials**: Uses macOS native vibrancy and blur layers.
- **Visual Customization**: Controllable glass blend styles, tint hues, and selection glow intensity.

### Window Management
- **Live Window Tabs**: Displays open, non-minimized windows as individual tabs on the taskbar.
- **Window Switching**: Click a tab to focus the window, click again to minimize, or click a minimized tab to unminimize.
- **Cmd+Tab Integration**: Supports 3 and 4-finger swipe gestures for window switching.
- **Hover Previews**: Displays thumbnail previews when hovering over window tabs.

### Start Menu & System Hub
- **Start Orb**: Circular button in the bottom-left corner that opens the Start Menu.
- **Search Integration**: Live-filters apps and recent files.
- **Pinned Apps Grid**: Drag-to-reorder grid for quick access to pinned applications.
- **All Apps List**: Alphabetical list of installed applications.
- **Recent Files**: Displays recently modified files using Spotlight metadata.

### App Launcher
- **Pinned Tray**: Pinned applications appear next to the Start Orb.
- **Launch & Focus**: Click to launch closed apps or raise windows for running apps.
- **Minimize**: Click an active app's icon to minimize all its windows.
- **Pinning**: Right-click any open window tab to pin the application to the taskbar.

### Utilities
- **Quick Search**: Inline taskbar search field that triggers macOS Spotlight.
- **Trash Shortcut**: Button on the right edge of the taskbar to open the Trash folder in Finder.

### Multi-Display Support
- **Display Targeting**: Can be configured to appear on all displays, main display only, or external displays only.
- **Contextual Anchoring**: The Start Menu and popovers open on the display where the click occurred.

### Appearance Settings
Configurable via the Appearance Lab popover:
- **Glass Blend Style**: Multiple blur and transparency modes.
- **Tint Controls**: Color picker for taskbar tint and opacity sliders for density.
- **Bevel Highlight**: Toggleable 0.5pt top edge highlight.
- **Layout Options**: Toggles for the Spotlight search field and icon-only mode for window tabs.

## Usage Guide

| Action | Execution |
|---|---|
| Open Start Menu | Click the Start Orb (bottom-left) |
| Switch to Window | Click the application's tab |
| Minimize Window | Click the active application's tab |
| Launch Pinned App | Click the icon in the pinned tray |
| Pin App to Taskbar | Right-click a window tab -> Pin to Bar |
| Pin App to Start Menu | Right-click a window tab -> Pin to Start |
| Open Trash | Click the Trash icon (bottom-right) |
| Customize Appearance | Click Start Orb -> Appearance Lab |
| Emergency Exit | Press `Cmd+Opt+Ctrl+Shift+Q` to quit AeroBar |
